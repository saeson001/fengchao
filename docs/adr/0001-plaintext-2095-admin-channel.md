# ADR-0001: 管理通道走 Cloudflare 前置的明文 HTTP 2095 端口

日期：2026-11-04
状态：已接受

## 背景

v2c 服务端部署在 185.115.207.27，该 IP 已被 GFW 整体黑洞（全端口直连不通）。手机与 PC 都无法直连。现有唯一可用通道是 Cloudflare 前置域名 `3x.820804.xyz:2095`（CF 固定 HTTP 端口，socat 转发到 VPS 的 v2c 5000 端口）。2095 属于 CF 的 HTTP 端口组，流量为明文 HTTP。

## 决策

凤巢的全部管理 API 调用走 `http://3x.820804.xyz:2095`，接受明文传输。管理密码经此通道传输。

## 理由

- 个人使用，密码仅保护管理端，不保护代理流量本身
- 现有订阅分发（`/d/<token>`）本来就走同一明文通道，安全水平一致
- CF 的 HTTPS 端口（2053/8443 等）要求回源也是 HTTPS，需要给 v2c 加 TLS 并调整 185 的端口占用，成本高收益低
- 后续若要加密，可单独升级（v2c 加 TLS + 换端口），凤巢只需改服务器地址设置

## 后果

- 管理密码在路径上可见（明文 HTTP）。风险接受
- 依赖 CF 与 socat 通道的可用性；通道变更时只需在设置里改服务器地址
